# Contributing to documentation

Open a documentation issue with the affected guide, expected correction and a
sanitized example. These public files are generated from the private canonical
documentation exporter. Maintainers must reconcile approved changes into that
source before regeneration; export manifests protect unrelated local edits.

Do not add SDK implementation, runtime binaries, raw models, real licences or
customer captures. Public examples must use canonical product imports, compile
against the current source contract and retain platform/release limitations.
Changes here do not authorize package publication, sales activation or deployment.
