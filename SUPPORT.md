# AresWord support

Use [AresWord issues](https://github.com/Ares-Defence-Labs/AresWord/issues)
for documentation corrections and sanitized reproducible SDK reports. Include
version, Flutter/Dart versions, OS/browser, integration mode, expected/actual
behavior and a minimal synthetic document. Availability of support or response
times is governed by your agreement; no SLA is implied here.

Do not attach customer documents/captures, licence tokens, private keys, model
resources or private implementation. Use [security reporting](SECURITY.md) for
security issues. Current customer package availability and known limitations are
tracked in [release status](docs/release-status.md). For product information and
current commercial options see [Ares Defence Labs](https://aresdefencelabs.com/development-sdks).
