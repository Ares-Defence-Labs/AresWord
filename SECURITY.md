# Security reporting

Do not post licence tokens, customer documents, model weights, signing material
or exploitable details in public issues. Request the project's private security
reporting channel through the repository's maintainers. If GitHub private
vulnerability reporting is enabled, use it. Do not assume that feature is enabled.

This documentation repository is pre-release. The protected AresWord customer
artifact has not yet passed the release gates. See
[security and assets](docs/security-and-assets.md).
